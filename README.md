# System & Security Tools

A collection of custom scripts and utilities for Windows and Linux systems.

## 📁 Repository Structure

This repository is organized by operating system and specific use cases. Each directory contains its own specialized scripts and dedicated documentation:

* **[`/windows`](./windows)** — PowerShell and batch scripts for Windows.
* **[`/linux`](./linux)** — Bash and Python scripts for Linux.
